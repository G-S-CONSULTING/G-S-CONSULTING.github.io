Application de suivi de chantiers

Plus de 300 chantiers par an. Excel abandonné.

Contexte. Un fichier Excel partagé, sans historique ni fiabilité, pour une société de terrassement.

Solution. Application web interne (cycle de vie des chantiers, base des sites de décharge cartographiée), développée avec Claude Code, déployée en interne, maintenable par une seule personne.

Restitution financière visuelle des bilans

Un service inédit, livré avec chaque bilan.

Contexte. Le bilan annuel remis sous forme de liasse, illisible pour un non-comptable.

Solution. Skill Claude qui transforme le bilan PDF en infographie HTML autonome (chiffres clés, ratios, évolution N/N-1), lisible sur mobile, publiable en ligne pour le banquier ou les fournisseurs.
